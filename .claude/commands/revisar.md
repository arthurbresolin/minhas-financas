---
description: Revisa as mudanças do git antes do commit
---

Revise o que mudou neste projeto.

1. Rode `git status` e `git diff` (e `git diff --staged`).
2. Aponte, em português simples: bugs de verdade, segredos vazados, código morto.
3. Não invente problema de estilo se o projeto não segue esse padrão.
4. Termine com um veredito curto: pode commitar ou não, e por quê.

Não faça alterações — só revise.
